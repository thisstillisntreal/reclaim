# Reclaim Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A PowerShell 5.1 CLI that measures, explains, plans, quarantines (never deletes), undoes and visualizes disk usage on the owner's Windows box, logging every run to the hub.

**Architecture:** C# 5 engine (`src/Engine.cs`, compiled by `Add-Type`, cached DLL) does the walk, classification, growth comparison and verified moves. PowerShell files in `src/` own commands, prompts and output. Knowledge base is JSON (`kb/knowledge-base.json` + optional gitignored `kb/local.json`).

**Tech Stack:** Windows PowerShell 5.1, .NET Framework 4.x (C# 5 via CodeDom), Win32 (`GetFileInformationByHandleEx`), hub client (python, path from gitignored `config.local.json`).

## Global Constraints

- No real deletes. Only verified moves into `Y:\_reclaim\quarantine\<date>\<receipt-id>\` or `Y:\_reclaim\moved\<receipt-id>\`.
- System actions (hiberfil, pagefile, DISM, shadow copies) are print-only.
- No LLM in plan/apply. Advisor output labeled ADVISORY.
- Every printed size: on-disk first, logical beside it.
- Mode banner (ELEVATED / UNELEVATED) on every run; denied paths listed.
- Additive only on the hub: new keys `task-reclaim`, `worklog-reclaim` only.
- Public repo: no secrets, no key paths, no personal data. Machine-specific values in gitignored files.
- Runs under `powershell.exe` 5.1; C# limited to C# 5 syntax.

Execution note: executed inline by one agent (owner: "don't stop until fully functional"),
TDD per task, fresh-context critic review after tasks 5 and 7. Implementation bodies are
written directly in the repo; this plan fixes files, interfaces, tests and verification.
